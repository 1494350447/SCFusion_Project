# SCFusion_Project

轻量实现：基于论文“SCFusion: Spatial-Channel Cross-Frequency Guided Fusion Network for Infrared-Visible Image Object Detection”的模型骨架与训练/测试脚本。

快速开始：

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 修改配置文件并准备数据后，运行训练：

```bash
python train.py --config configs/vt5000_config.py
```
